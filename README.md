# 📚 Projetos de Curso: `projetos_gerais`

Diferente das outras branches que contêm projetos únicos e extensos, esta branch é dedicada a **exercícios e mini-apps desenvolvidos durante as aulas**.

---

### 🚀 O que você encontrará aqui?
Este é o meu repositório de fixação técnica. Aqui estão todos os códigos criados para acompanhar o currículo do curso, incluindo:

* **Fixação de conteúdo:** Exercícios práticos após cada módulo teórico.
* **Algoritmos e Lógica:** Scripts feitos para entender estruturas de repetição, condicionais e tipos de dados em Dart.
* **Fundamentos:** Exemplos iniciais de Programação Orientada a Objetos (POO) aplicados em pequenos projetos.

---

### 🗂️ Organização do Aprendizado

| Tipo de Conteúdo | Objetivo |
| :--- | :--- |
| **Scripts de Lógica** | Dominar a sintaxe base e manipulação de dados. |
| **Mini-projetos** | Aplicar conceitos em pequenos cenários reais propostos pelo instrutor. |
| **Testes de Módulos** | Código rápido para validar funcionalidades específicas de pacotes ou da linguagem. |

---

### 🏁 Como navegar
Como esta branch contém múltiplos arquivos e pequenos scripts, a melhor forma de explorar é:

1.  Verificar o nome dos ficheiros/pastas, que seguem a ordem do cronograma do curso.
2.  Executar os scripts individualmente usando o comando:
    ```bash
    dart run nome_do_arquivo.dart
    ```
