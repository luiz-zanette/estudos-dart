📌 Sobre esta Branch: apps_aleatorios
Diferente das outras branches deste repositório, que contêm projetos estruturados e finalizados durante cursos específicos, a branch apps_aleatorios é o meu laboratório pessoal.

🧪 O que você encontrará aqui?
Esta branch funciona como um hub de pós-estudo. Após concluir os projetos guiados dos cursos (que se tornaram as branches principais), utilizo este espaço para:
•	Fixação de conteúdo: Aplicar de forma independente o que foi aprendido.
•	Novos desafios: Criar mini-aplicativos para testar lógicas específicas em Dart.
•	Exploração: Testar funcionalidades que não foram abordadas no material original.

🔀 Organização do Repositório
•	Branches de Curso: Projetos estruturados com base em cronogramas de aprendizado;
•	Branch Atual (apps_aleatorios): Foco em prática livre, autonomia e experimentação contínua.
